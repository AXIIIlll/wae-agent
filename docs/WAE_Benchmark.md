# 可重跑評測（Benchmark）

## 目標

用固定任務集與固定判定訊號，量測「語音 → 執行」的真實成功率，而不是靠感覺。

## 判定訊號（唯一可信來源）

- `WAE_EXEC: taskResult=SUCCESS|FAIL seq=N`（logcat）
- `WAE_VOICE: SHERPA_TEST <ms>` / `SHERPA_READY`（離線引擎）
- `WAE_VOICE_GATE: accept|reject`
- `WAE_EXEC: Decomposed rawCommand=...`

## 跑法

1. 語音基線（WAV 注入，不需說話）：
   `powershell -File tools/voice_baseline.ps1 -WavDir E:\WAE\temp\voice_base`
2. 端到端（真人）：照 tasks 逐一講，記錄 logcat。
3. 產出 CSV：`docs/benchmark_results.csv`（時間、ASR ms、文字、taskResult）。

## 通過門檻

- 安靜：≥ 90%（每句 ×3 次）
- 噪音（60dB）：≥ 75%
- 端到端延遲 p50 ≤ 2.5 秒
- 噪音誤動作：30 分鐘 0 次
