# 喚醒詞（Hey WAE）規格

> 現況：無喚醒詞；入口為電源鍵/助理鍵（預設助理）、快捷設定磚、懸浮窗。

## 需求

- 使用者說「Hey WAE」即可叫出助理，不需碰手機（螢幕亮/暗皆可）
- 完全離線、不上傳音訊
- 不顯著影響電力（目標：待機功耗增加 < 3%/天）

## 技術方案（建議）

1. **前景服務 + 關鍵詞偵測（KWS）**
   - 引擎：sherpa-onnx KWS（Apache-2.0）＋小模型（< 5MB）
   - 服務類型：`microphone` 前景服務（Android 14 需宣告）
   - 常駐通知（必要，Android 規定）
2. **喚醒後**：啟動 AssistActivity（或直接進 sherpa 串流辨識）
3. **省電策略**：僅在螢幕關閉或耳機連接時開 KWS；其餘時間關閉

## 風險

- 電池與發熱（需實測）
- Android 14 前景麥克風限制與使用者觀感（常駐通知）
- 誤喚醒（需門檻調校）

## 驗收

- 5 公尺、正常音量喚醒率 ≥ 90%
- 24 小時誤喚醒 ≤ 3 次
- 待機耗電增加 ≤ 3%/天
