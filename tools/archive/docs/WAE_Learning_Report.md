# WAE 學習歷程（自學申請用）

## 一、學習主題

「離線可驗證的個人手機代理人」：在完全不連網的 Android 手機上，用語音把跨 App 任務做完，
並讓每一步可被檢驗。對應十二年國教核心素養：科技資訊與媒體素養、系統思考與解決問題、
規劃執行與創新應變。

## 二、學習過程（可驗證的證據）

- 程式碼：231 個 Kotlin 檔、42,421 行（主程式 30,245、測試 12,176）
- 測試：745 個單元測試全綠
- 資料：51 個 TSV、252,006 列（能力/詞表/策略全資料驅動）
- 文件：16+ 篇設計文件（含北極星、缺口稽核、評測、喚醒詞規格）
- 真機驗證：離線語音 E2E（飛航模式 → 辨識 → 執行 → `taskResult=SUCCESS`）

## 三、關鍵失敗與修正（學習證據）

1. Vosk 模型品質不足 → 換 sherpa-onnx 內建模型（並解決 ONNX Runtime 雙版本衝突）
2. 噪音被當指令執行 → 加入能量 VAD、指令閘門、風險分級
3. 助理 UI 擋住目標畫面 → 先關 UI 再送指令（500ms handoff）
4. 16KB page size 導致崩潰 → 升級原生庫並驗證 LOAD 對齊
5. hotwords 造成 native crash → 回退並改用資料驅動誤認修正表

## 四、反思

- 學會用「可量測的判定訊號」而不是「看起來會動」來確認功能
- 學會區分「能跑」與「可信」：安全紅線（金流/刪除）必須人工確認
- 學會用 AI 協作，但對每個模組能說明原理、限制與驗證方式

## 五、下一步

真人語音基線、undo/歷史、Task OS 長任務、多機相容、公開 benchmark、
最後目標是「可驗證的離線手機代理人」。
